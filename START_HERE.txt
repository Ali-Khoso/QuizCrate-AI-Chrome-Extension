QUIZCRATE AI — RED THEME
========================

FASTEST TEST (NO API KEY REQUIRED)
1. Unzip this folder.
2. Open Google Chrome: chrome://extensions
3. Enable Developer mode.
4. Click Load unpacked and choose the "extension" folder.
5. Click the QuizCrate AI toolbar icon to open its side panel.
6. Choose "Explore the interactive demo".
7. Pick Analysis of Algorithms, select lectures, click Generate.

REAL GOOGLE CLASSROOM
1. Set up your Chrome Extension OAuth Client in Google Cloud.
2. Paste its Client ID in extension/manifest.json.
3. Enable Google Classroom API and Google Drive API.
4. Start the server with your Gemini API key in server/.env.
5. Reload Chrome extension and choose Connect Google Classroom.

READ README.md FOR COMPLETE STEP-BY-STEP SETUP AND LIMITATIONS.

This is a local MVP; it has not been published to Chrome Web Store.
